🛡️ Elegoo Uno R3 FIDO2 (CTAP2 CBOR) & USB HID 実験ラボ

ATmega16U2 ネイティブ USB HID (0xF1D0) ＋ ATmega328P FIDO2 パスキーエンジン

🌐 Windows 標準 WebAuthn API テスト (ATmega16U2 USB HID モード) Native USB HID (0xF1D0)

ATmega16U2 を USB HID 化した後は、COMポート接続不要で Windows OS 標準のセキュリティキー画面（navigator.credentials） から直接 Elegoo Uno R3 を FIDO2 キーとして使用できます！（※要求が来ると Uno R3 の LED が 2.5秒間点滅したあと自動タッチ承認して約5〜9秒で計算完了します）

接続ステータス: 未接続

🚀 FIDO2 パスキー登録 (MakeCredential) CTAP2 CBOR (0x01)

CBOR エンコードされたリクエストを送信し、77バイト COSE_Key を含む 148バイト authData と packed 署名を検証します。
